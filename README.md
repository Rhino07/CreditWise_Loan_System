# 💳 CreditWise Loan Approval Prediction

CreditWise is a machine learning project that predicts **loan approval status** using supervised classification algorithms. The entire ML pipeline is implemented in a single Jupyter Notebook, demonstrating end-to-end data science skills.

---

## 📌 Project Overview

This project uses historical loan application data to predict whether a loan should be approved or rejected.

It demonstrates:

- Exploratory Data Analysis (EDA)  
- Data preprocessing  
- Feature engineering  
- Model training  
- Model evaluation  

The goal is to compare multiple ML models and determine which performs best for loan approval prediction.

---

## 🧠 Models Used

- K-Nearest Neighbors (KNN)  
- Logistic Regression  
- Naive Bayes  

These models allow comparison between distance-based, linear, and probabilistic approaches.
